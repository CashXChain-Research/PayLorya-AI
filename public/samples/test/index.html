Test invoices

One text and one PDF invoice per scenario, each with its own invoice number, so both run. Testnet and sandbox only: tADA on Cardano Preprod, fiat on the CashXChain sandbox (no real money). Open the demo

Before a full run

  1. The server needs APPROVE_TOKEN: every payment and budget change asks for it once per tab.
  2. Agent settings, Budget: set Verification checks to 50 tADA (18 paid checks of 2 tADA) and Fiat payouts per session to 10. The buyer wallet needs about 50 tADA.
  3. Upload a PDF or text file with the paperclip in the Assistant (or paste the text). At most 10 invoices per minute.
  4. Duplicate check: send any payable file a second time. It is refused before anything is paid.
